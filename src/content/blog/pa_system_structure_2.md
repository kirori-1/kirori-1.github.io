# 第二章：系统构成与信号流程

## 2-1 基本概念：音响系统信号路径

音响系统的信号路径通常如下：

```
Input → Mixer → Output (FOH / Monitor / AUX) → Amplifier → Speaker
```

### 输入（Input）类型

| 类别         | 示例           | 说明                             |
| ------------ | -------------- | -------------------------------- |
| 电声乐器输入 | 电吉他、合成器 | 通常需使用 DI 盒转换为平衡信号   |
| 话筒输入     | 人声、乐器拾音 | 动圈式或电容式，电容式需幻象供电 |
| 播放器输入   | CD、电脑等     | 线路电平信号，注意电平匹配       |

**术语举例（日文）**：

- マイク（Mic）
- スタンド（Mic Stand）
- ケーブル（Cable）
- DI（DI Box）

---

## 2-2 Output 分支说明

### 主要输出方向

| 路径            | 说明                 | 接线设备                        |
| --------------- | -------------------- | ------------------------------- |
| FOH（主扩）     | 面向观众的主扩音系统 | Mixer → FOH Out → Amp → Speaker |
| Monitor（监听） | 演员/演奏者舞台监听  | Mixer AUX Send → Amp → Monitor  |
| 录音/中继输出   | 给录像/录音设备使用  | Mixer REC OUT 或 AUX OUT        |

### 实际设置举例（参考笔记）：

- **Input:** KB 用 = ST-259B
- **Output:** FOH → 2ch，G1 → FOH
- **AUX Monitor:**
  - 上手モニタ
  - 下手前モニタ
  - 下手側モニタ
  - Drs モニタ

## 2-3 Fader 操作术语

| 名称       | 缩写 | 操作意义     | 音量变化状态             |
| ---------- | ---- | ------------ | ------------------------ |
| fade in    | F.I  | 渐入         | 音量逐渐增加             |
| fade out   | F.O  | 渐出         | 音量逐渐减少             |
| sneak in   | S.I  | 偷偷进入     | 小音量突然出现           |
| sneak out  | S.O  | 偷偷退出     | 小音量突然消失           |
| cut in     | C.I  | 突然插入     | 音量瞬间增加             |
| cut out    | C.O  | 突然剪除     | 音量瞬间消失             |
| cross fade | C.F  | 交叉淡入淡出 | 一个声音淡出，另一个淡入 |

**配合舞台 Cue 使用术语（日文）**：

- スタート（开始）
- スタンバイ（待命）
- マイクロホンに近づいて（靠近麦克）

## 2-5 话放（Preamp）基础

话放是用于将微弱的话筒信号提升至线路电平的放大器模块，常内建于调音台或音频接口中。

### 分类

| 类型     | 特点                     | 用途                     |
| -------- | ------------------------ | ------------------------ |
| 模拟话放 | 声音自然，无延迟         | 传统调音台、舞台扩声     |
| 数字话放 | 可远程控制，支持场景存储 | 数字调音系统、广播、录音 |

### 幻象电源（Phantom Power）

为电容麦克风提供 +48V 直流电，常由话放模块通过 XLR 线供电。

## 2-6 AUX 发送与监听系统

AUX（辅助输出）通道通常用于监听、效果器发送或子混音处理。

### 常见应用

| 发送对象        | 用途                 | 路径                       |
| --------------- | -------------------- | -------------------------- |
| 舞台监听音箱    | 提供个人监听混音     | AUX Send → Amp → Monitor   |
| 耳返系统（IEM） | 演员/歌手个人监听    | AUX Send → IEM Transmitter |
| 效果器          | 外接混响、延迟等设备 | AUX Send → FX → Return     |

### AUX 类型

| 类型       | 说明                         |
| ---------- | ---------------------------- |
| Pre-Fader  | 不受主音量推子影响，适合监听 |
| Post-Fader | 受推子影响，适合效果器发送   |

> 📌 在舞台监听配置中，需与演出者确认每路 AUX 内容，如主唱希望多监听自己的人声、鼓手需监听点击等。
