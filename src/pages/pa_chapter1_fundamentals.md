# 第一章：音响基础与声学原理

## 1-1 声音的物理特性

| 属性       | 定义说明                        |
|------------|---------------------------------|
| 频率 (Hz)  | 声波每秒振动次数，决定音高     |
| 振幅       | 声波的波峰高度，决定音量       |
| 波长       | 一个完整周期的空间长度         |
| 相位       | 同频率声波之间的时间偏移       |
| 声速       | 空气中约为 343 m/s（20°C）     |

---

## 1-2 分贝（dB）与音量计算

分贝是一种**相对单位**，常用于表示音压、电压、功率的对比。

### 电压增益公式：

```
dB = 20 × log10(V1 / V0)
```

### 功率增益公式：

```
dB = 10 × log10(P1 / P0)
```

常见参考值：
- 0 dBu ≈ 0.775 V
- 0 dBV = 1.0 V

---

## 1-3 THD（总谐波失真）

总谐波失真表示信号中**除基频外的谐波成分占比**。

```
THD(%) = √(V2² + V3² + ... + Vn²) / V1 × 100%
```

- V1 为基波电压，V2~Vn 为各次谐波分量
- THD 越低，信号越纯净

---

## 1-4 Δt（时间差）与距离

声音传播距离 = 声速 × 时间差

例如：

```
Δt = 5ms
距离 = 343 m/s × 0.005s = 1.715 米
```

此原理常用于：
- 延时器设置
- 相位校正
- 多扬声器布置中避免回声干扰
